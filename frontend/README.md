# ClipIQ Frontend

React + Vite frontend for ClipIQ, a source-cited RAG chatbot that compares one YouTube video against one Instagram Reel.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Environment

Create `.env.local`:

```bash
VITE_API_BASE_URL=http://localhost:8000
```

## Deployment

This app is Vercel-ready. Use the default Vite settings:

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
